# Student CRUD API - Git and GitHub Lab Record

## Objective

Practice source code management using Git and GitHub by uploading the Student CRUD API.

## Tools Used

- VS Code
- Git
- GitHub
- Node.js

## Repository

GitHub repository: https://github.com/bharadwajreddy07/CRUD-Backend

## Git Procedure

```bash
git init
git status
git add .
git status
git commit -m "Add CRUD backend - 23071A0584"
git log --oneline
git remote add origin https://github.com/bharadwajreddy07/CRUD-Backend.git
git remote -v
git branch -M main
git push -u origin main
```

The API source is in `server.js`. Install dependencies with `npm install` and run it with `npm start`.
